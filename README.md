# ساخت خودکار FraudWorkflow.exe با GitHub Actions

این پوشه یک گردش‌کار (workflow) گیت‌هاب است که فایل اجرایی ویندوز ۳۲ بیتی را
به‌صورت خودکار و بدون نیاز به هیچ کامپیوتر ویندوزی شخصی می‌سازد. خودِ سرورهای
گیت‌هاب (ویندوز واقعی با اینترنت) ساخت را انجام می‌دهند.

## مراحل یک‌بار راه‌اندازی

۱. یک حساب رایگان در https://github.com بسازید (اگر ندارید).

۲. یک مخزن (Repository) جدید بسازید:
   - روی «+» بالا سمت راست → New repository
   - نام دلخواه (مثلاً fraud-workflow) → Private یا Public → Create repository

۳. این سه مسیر/فایل را داخل مخزن آپلود کنید (دکمه‌ی "Add file" → "Upload files"
   در صفحه‌ی مخزن؛ مرورگر پوشه‌ها را هم نگه می‌دارد اگر کل این پوشه را
   به‌صورت یک‌جا بکشید و رها کنید):
   - fraud_workflow.py                 (کنار همین README بگذارید، از چت قبلی)
   - requirements_workflow.txt         (کنار همین README بگذارید، از چت قبلی)
   - .github/workflows/build-exe.yml   (همین فایل، با همین مسیر دقیق)

   نکته‌ی مهم: fraud_workflow.py و requirements_workflow.txt باید در ریشه‌ی
   مخزن باشند (نه داخل پوشه‌ی .github). فقط build-exe.yml باید داخل مسیر
   .github/workflows/ بماند.

۴. روی "Commit changes" کلیک کنید تا آپلود نهایی شود.

## اجرای ساخت

به‌محض آپلود فایل workflow، ساخت خودکار شروع می‌شود. برای اجرای دستی یا
اجراهای بعدی:

۱. در صفحه‌ی مخزن، به تب "Actions" بروید.
۲. روی "Build FraudWorkflow.exe (Windows 32-bit)" در فهرست سمت چپ کلیک کنید.
۳. دکمه‌ی "Run workflow" (سمت راست) → دوباره "Run workflow" را بزنید.
۴. حدود ۱ تا ۳ دقیقه صبر کنید تا دایره‌ی زرد به ✔ سبز تبدیل شود.

## دانلود فایل exe

۱. روی همان اجرای سبزرنگ در تب Actions کلیک کنید.
۲. پایین صفحه، بخش "Artifacts" را ببینید.
۳. روی "FraudWorkflow-win32-exe" کلیک کنید تا یک فایل zip دانلود شود.
۴. zip را باز کنید؛ داخل آن FraudWorkflow.exe است — همان فایل نهایی تحویل پروژه.

## اگر بعداً نرم‌افزار را اصلاح کردم

کافی است نسخه‌ی جدید fraud_workflow.py را در همان مخزن جایگزین قبلی کنید
(Add file → Upload files، یا ویرایش مستقیم در گیت‌هاب). ساخت exe دوباره
خودکار اجرا می‌شود و فایل تازه در Artifacts قرار می‌گیرد.
